# Клиент CutSheet (Flutter Desktop)

Клиент (ТЗ 5.1): вход и регистрация, список проектов, новый проект с загрузкой видео и сценария,
ход обработки по этапам, редактор монтажного листа со встроенным плеером (этап 4) и экспорт
(этап 5). Статус обработки приходит в реальном времени через SignalR.

Дизайн — [макет CutSheet](https://claude.ai/artifact/NBzfXGCCkqqjjHr2gweoSy): тёплый серый фон,
белые панели, заголовки Lora, интерфейс и таблица — Carlito (Lato с кириллицей), таймкоды —
IBM Plex Mono (шрифты в `fonts/`, лицензия OFL), иконки — Gravity UI (`lib/src/ui/gravity_icons.dart`,
MIT). Синий цвет — правки человека, выделение и фокус; янтарный — низкая уверенность модели.
Токены и общие компоненты — `lib/src/ui/`.

Редактор: ячейки (таймкоды `ЧЧ:ММ:СС:КК`, план, описание) правятся на месте и сохраняются сами;
реплики — в окне по клику на ячейку диалогов. Правки помечены синей точкой и подписью
«Изменено вами · Вернуть авто»; сомнительные результаты автоматики и реплики не из сценария
подсвечены янтарным. Фильтры «Все / Проверить / Изменённые» и поиск по листу. Над таблицей и по
правому клику: разделить (точка по кадрам, предпросмотр двух строк), объединить со следующей,
удалить. Клик по строке перематывает плеер, двойной клик играет сцену; справа — шкала сцен и
уверенность модели по выбранной строке. Если строку успели изменить в другом окне или повторной
обработкой, клиент показывает обе версии и даёт выбрать. Переключатель «Без правок» — режим FR-C12.
Экспорт: формат, колонки (`options.columns` в export-сервисе) и последние файлы со скачиванием.

Клиент ходит только в Kong (`http://localhost:8000`: `/api/v1/...` и хаб `/hubs/projects`),
а видео и сценарий грузит частями напрямую в MinIO по presigned URL от Project API. Если загрузка
оборвалась, кнопка «Продолжить загрузку» догружает только недостающие части.

## Запуск

Нужен Flutter 3.38+ и поднятое окружение (`make up` в корне репозитория). Плеер — media_kit
(libmpv): на Windows и macOS библиотеки приезжают с пакетом, на Linux нужен `libmpv-dev`
(`sudo apt install libmpv-dev mpv`).

```sh
cd client
flutter pub get
flutter run -d windows        # или macos, linux
```

Другой адрес шлюза: `flutter run -d windows --dart-define=API_BASE=http://192.168.1.10:8000`.
Тогда и MinIO должен быть доступен клиенту: `S3_PUBLIC_ENDPOINT=http://192.168.1.10:9000`
в `deploy/.env`.

Токены хранятся в защищённом хранилище ОС (Windows Credential Manager, Keychain, libsecret
на Linux); refresh-токен обновляется сам.
