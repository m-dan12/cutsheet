# Контракты событий

- `schemas/envelope.v1.json` — общий конверт (ТЗ 4.1).
- `schemas/defs.v1.json` — общие типы: `s3_uri`, мс, `confidence`, план, реплика.
- `schemas/events/<топик>.v<версия>.json` — схема события целиком (конверт + payload).
  Имя топика совпадает с `event_type`.
- `topics.txt` — реестр топиков (партиции, retention). Из него `deploy/kafka/create-topics.sh`
  создаёт топики при старте; автосоздание в брокере выключено.
- `examples/` — по валидному примеру на каждое событие.

Правила изменения (ТЗ 4.1): необязательное поле можно добавить в текущую версию;
ломающее изменение — новый файл `<топик>.v2.json` и параллельная поддержка обеих версий.

`make test-contracts` проверяет, что у каждого топика есть схема и пример и что примеры
валидны. Генерация моделей для C# и проверка обратной совместимости в CI — следующий шаг.
