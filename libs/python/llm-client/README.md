# llm-client

Заглушка этапа 0. Общий слой доступа к LLM (ТЗ 5.10), реализация — этап 2.

- Клиент OpenAI-совместимого API: `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`, таймауты из окружения.
- Локальная модель (Ollama / vLLM) или внешняя — только конфигурацией.
- Текстовые и мультимодальные запросы, структурированный вывод по JSON-схеме с валидацией и повтором.
- В лог пишутся модель, версия промпта, длительность и токены; содержимое запросов — нет.
