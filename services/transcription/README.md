# Transcription & Alignment

Читает `video.uploaded` и `script.parsed`, публикует `dialogue.aligned` (ТЗ 5.5).

- **Распознавание** (FR-TA1, FR-TA2): аудио из видео через ffmpeg (16 кГц моно), затем
  faster-whisper (CPU, по умолчанию) или WhisperX (GPU, пословное выравнивание wav2vec2) с
  пословными таймкодами. Язык — `payload.language` события, иначе `TA_LANGUAGE`; пустое
  значение — автоопределение. Видео без звука даёт пустой транскрипт.
- **Кэш и ожидание второго входа**: транскрипт — `projects/{id}/transcript/transcript.json`,
  разобранный сценарий — `projects/{id}/transcript/script.json`. Тот же файл видео с той же
  моделью и языком повторно не распознаётся. Сопоставление запускается, когда есть оба входа,
  в любом порядке прихода (FR-TA3). `event_id` результата выводится из id обоих входных событий.
- **Сопоставление** (`align.py`, FR-TA3–TA5), устойчиво к перестановкам сцен монтажом,
  вырезанным репликам, импровизации и ошибкам распознавания:
  1. для каждой реплики сценария — кандидаты в транскрипте по совпадающим словам (точно или
     по префиксу, частые слова не голосуют);
  2. уточнение локальным выравниванием Смита — Уотермана с нечётким сравнением слов
     (Левенштейн), оценка — F1 по совпавшим словам (`confidence`);
  3. жадный выбор от самых надёжных пар: каждая реплика и каждое слово речи — не больше
     одного раза, порядок сценария не обязателен;
  4. короткие реплики («Да.») ищутся только в промежутке между найденными соседями;
  5. речь вне реплик сценария — реплика с `role = null`, `matched = false` (FR-TA5).

| Переменная | По умолчанию | |
|---|---|---|
| `TA_BACKEND` | `faster-whisper` | `whisperx` (образ с `TA_EXTRAS=whisperx`) или `gigaam` (`TA_EXTRAS=gigaam`) |
| `TA_MODEL` | `small` | модель Whisper; на GPU — `large-v3` (ТЗ 9, п. 8) |
| `TA_GIGAAM_MODEL` | `v3_e2e_rnnt` | модель GigaAM (`v3_e2e_ctc`, `v3_rnnt`, `v3_ctc`, …) |
| `TA_GIGAAM_TIMING` | `whisper` | откуда таймкоды слов для GigaAM: `whisper` или `vad` |
| `TA_DEVICE` | `auto` | `cpu` / `cuda` |
| `TA_COMPUTE_TYPE` | `default` | `int8` для CPU, `float16` для GPU |
| `TA_LANGUAGE` | `ru` | пусто — автоопределение |

Модели Whisper скачиваются с Hugging Face при первом распознавании в том `whisper-models`.

**GigaAM** (`giga.py`) — русская модель Сбера, на обычной русской речи заметно точнее Whisper,
но отдаёт только текст фрагментов до 25 с, без таймкодов слов. Поэтому речь режется на
фрагменты до 22 с по словам Whisper (`TA_GIGAAM_TIMING=whisper`, модель — `TA_MODEL`) или по
Silero VAD (`vad`), каждый фрагмент распознаёт GigaAM, а таймкоды его слов переносятся с
совпавших слов Whisper; несовпавшие слова и режим `vad` получают таймкоды пропорционально
длине слова. Это вариант G2 эксперимента 03а. Образ для CPU:
`TA_EXTRAS=gigaam TORCH_INDEX=https://download.pytorch.org/whl/cpu` (torch без CUDA). Веса
GigaAM качаются с CDN Сбера в `/models/gigaam`.

GPU-образ: `TA_EXTRAS=whisperx` ставит whisperx с torch. Для работы на GPU в Docker нужен
NVIDIA Container Toolkit (в WSL 2 — драйвер NVIDIA для Windows) и `gpus: all` у сервиса;
базовый образ с CUDA подберём, когда будет понятно, на какой машине идут замеры.

Несколько экземпляров сервиса могут одновременно увидеть оба входа и опубликовать результат
дважды, но с одним и тем же `event_id`: Aggregator отбросит дубликат.
